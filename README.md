# Calculator

A calculator built with plain HTML, CSS and JavaScript.

- Add, subtract, multiply, divide, percent, plus/minus and decimals
- Chained operations, division-by-zero handling, no floating-point noise (0.1 + 0.2 = 0.3)
- History panel: click a past result to reuse it (saved in the browser)
- Full keyboard support: digits, `+ - * /`, `Enter`, `Backspace`, `Esc`
- Copy result, light and dark theme, responsive

Open `index.html` in a browser. No build step is needed.
